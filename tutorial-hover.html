Como usar o sistema

Cabeçalho de UFs

Selecione uma UF para filtrar os credenciados.

Os balões mostram a quantidade de novos credenciados por estado.

Cards de Novos Credenciados

Lista filtrada pela UF ou Estado selecionado.

Use os campos de busca para nome ou especialidade.

Mapa Interativo

Clique em um estado para filtrar os credenciados.

O estado será destacado no cabeçalho.
